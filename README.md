# Discount Rate Calculator Skill
## 项目简介
本项目是货币银行学简易贴现率计算小工具。
贴现公式：
贴现利息 = 票据面额 × 贴现率 × 贴现期
实付金额 = 票据面额 − 贴现利息

### 计算示例
票据面值 10000元，年贴现率4%，贴现期6个月
贴现利息=10000 * 4% * 0.5 = 200
银行实付金额=9800元

### 使用说明
输入票据面额、年化贴现率、剩余期限，快速算出贴现利息与实际兑付金额。
